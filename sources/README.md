# Data verification sources

Use this folder to keep manual verification notes for player and team data.

Recommended source roles:

- Transfermarkt: career paths, transfers, clubs, positions, market data, dates.
- Official club/federation sites: logos, current squads, official names.
- FIFA/UEFA/CONMEBOL: tournament matches, national teams, historic tables.
- Wikimedia/Wikidata: reusable images when available.

Avoid using Transfermarkt as an automatic image source. Use it mainly to confirm facts.
